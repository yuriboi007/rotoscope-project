Multimedia & Authoring

About This Portfolio

This portfolio serves as the final project for the Multimedia & Authoring course. It combines two major multimedia productions—a 3D Solar System Animation created in Blender and a Frame-by-Frame Rotoscope Animation. The website was designed to showcase the completed outputs, production process, documentation, and interactive features in one modern portfolio.

🪐 3D Rendering Project

The first project focuses on creating a realistic Solar System using Blender. Every planet was modeled, textured, animated, and rendered individually before being compiled into an interactive website. Visitors can watch the rendered animations, explore scientific information about each planet, use the planetary age calculator, and download the Blender project files used throughout development.

🎥 Rotoscope Project

The second project demonstrates the process of creating a rotoscope animation through frame-by-frame tracing and video editing. The website documents the weekly production progress, showcases the final rendered animation, and explains the techniques used throughout the project.
